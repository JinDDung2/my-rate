# Security Rules

보안, 개인 정보, 민감 데이터 취급 규칙이다.

## Secrets

- API 키, 토큰, 비밀번호, 인증 쿠키를 문서나 로그에 저장하지 않는다.
- `.env`, 키 파일, 인증 파일은 필요한 경우에도 출력 내용을 최소화한다.
- 예시 값은 실제 값처럼 보이지 않게 만든다.

## Data

- 금융 데이터는 출처와 조회 시점을 남긴다.
- 개인 조건, 소득, 계좌 정보 등 민감 정보는 필요한 범위에서만 다룬다.
- 외부에 전송되는 데이터가 있으면 목적과 범위를 확인한다.

## Operations

- 삭제, 초기화, 대량 변경, 외부 배포는 사용자의 의도를 확인한다.
- 의존성 설치나 외부 네트워크 접근은 필요한 이유를 설명한다.
