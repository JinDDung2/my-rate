## Summary

AI 해석 근거 원문과 미해석 우대폭 고지를 상품 상세 영역에 표시한다.

## Spec Reference

- F-08 근거 원문 표시
- F-09 미해석 우대폭 고지
- 8.2 출력 검증 규칙

## Scope

- 조건별 `evidence` 스팬 표시
- AI가 해석한 항목에 `AI 해석` 배지 표시
- 상품 전체 `spcl_cnd` 원문 토글 구현
- `G - Σ(추출된 조건 rate_bp) > 0.05%p` 조건에서 미해석 우대폭 고지 표시
- 미해석 우대폭은 내 금리에 반영하지 않음

## Acceptance Criteria

- [ ] 각 조건 카드에 원문 근거가 표시된다.
- [ ] 원문 전체를 토글로 열고 닫을 수 있다.
- [ ] AI 해석 항목에는 배지가 표시된다.
- [ ] 미해석 우대폭이 0.05%p를 초과하면 고지 문구가 표시된다.
- [ ] 미해석 우대폭은 내 금리에 가산되지 않는다.

## Verification

- [ ] 근거 원문 표시 수동 확인
- [ ] 미해석 우대폭 케이스 수동 확인
