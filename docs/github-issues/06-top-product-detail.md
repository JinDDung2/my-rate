## Summary

내 조건 기준 1위 상품 상세 카드와 광고 1위 대비 배지를 구현한다.

## Spec Reference

- F-06 광고금리 vs 내 금리 대비 표시
- 4. 화면 구성 [C] 1위 상품 상세 카드

## Scope

- 내 조건 기준 1위 상품 상세 카드 표시
- 광고 최고금리, 내 금리, 원금, 세후이자 표시
- 충족 조건과 미충족 조건을 우대폭과 함께 표시
- 최고우대금리 기준 1위와 내 조건 기준 1위가 다르면 배지 표시
- "광고 1위와 다릅니다" 문구 표시

## Acceptance Criteria

- [ ] 1위 상품 상세 카드가 랭킹 결과와 일치한다.
- [ ] 충족 조건과 미충족 조건이 구분되어 표시된다.
- [ ] 각 조건의 우대폭이 `%p` 단위로 표시된다.
- [ ] 광고 1위와 내 조건 1위가 다르면 배지가 표시된다.
- [ ] 두 1위가 같으면 배지가 표시되지 않는다.

## Verification

- [ ] 광고 1위와 내 조건 1위가 다른 데모 케이스 확인
- [ ] 조건 표시 수동 확인
