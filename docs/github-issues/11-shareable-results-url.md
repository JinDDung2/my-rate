## Summary

사용자 입력 상태를 URL 쿼리스트링으로 직렬화해 재현 가능한 공유 링크를 제공한다.

## Spec Reference

- F-11 결과 공유
- 11. 완료 정의

## Scope

- 월 납입액, 기간, 적립 방식, 선택 조건을 쿼리스트링으로 직렬화
- URL 진입 시 쿼리스트링에서 입력 상태 복원
- 공유 링크 복사 버튼 구현
- 잘못된 쿼리 값은 기본값 또는 유효값으로 보정

## Acceptance Criteria

- [ ] 현재 입력 상태를 URL로 복사할 수 있다.
- [ ] 복사한 URL로 접속하면 동일한 입력 상태가 복원된다.
- [ ] 복원 후 랭킹 결과가 원래 화면과 동일하다.
- [ ] 잘못된 쿼리 값은 앱을 깨뜨리지 않는다.
- [ ] 심사위원이 별도 로그인 없이 결과를 재현할 수 있다.

## Verification

- [ ] 공유 링크 복사 수동 확인
- [ ] 새 탭에서 상태 복원 수동 확인
- [ ] 잘못된 쿼리 값 처리 확인
