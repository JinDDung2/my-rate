## Summary

정액적립식/자유적립식과 단리/월복리 기준의 이자 계산 엔진을 구현한다.

## Spec Reference

- F-04 이자 계산 엔진
- 7. 계산 규칙 명세
- 7.5 검증 테스트 T1~T4

## Scope

- 순수 모듈 `lib/interest.ts` 구현
- 정액적립식 단리 계산
- 정액적립식 월복리 계산
- MVP 자유적립식은 매월 정액 납입으로 계산
- 세전이자, 세금, 세후이자, 만기수령액 반환
- 원 단위 반올림은 최종 1회만 수행

## Acceptance Criteria

- [ ] P=100,000, n=12, r=0.03, 단리의 세전이자가 19,500원이다.
- [ ] P=100,000, n=1, r=0.12, 단리의 세전이자가 1,000원이다.
- [ ] 동일 금리에서 월복리 이자가 단리 이상이다.
- [ ] r=0이면 이자와 세금이 0원이다.
- [ ] 세금은 `floor(세전이자 * 0.154)`로 계산된다.

## Verification

- [ ] 이자 계산 단위 테스트 통과
- [ ] 타입 체크 통과
