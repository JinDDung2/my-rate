## Summary

전 화면 고지, 접근성, 성능, 보안 관련 비기능 요구사항을 반영한다.

## Spec Reference

- F-12 고지 및 면책
- 10. 비기능 요구사항
- 11. 완료 정의

## Scope

- 전 페이지 하단 고정 고지 표시
- 금융자문 아님, 데이터 출처/기준월, 월 단위 근사 계산 안내
- 모바일 우선 반응형 레이아웃
- WCAG AA 수준 명도 대비 점검
- 조건 변경 후 결과 갱신 200ms 이내 유지
- 사용자 입력값 서버 로깅 금지
- 금액 천 단위 구분 표기

## Acceptance Criteria

- [ ] 금융자문 아님 고지가 전 화면에 노출된다.
- [ ] 데이터 출처와 기준월이 상시 노출된다.
- [ ] 자유적립식 MVP 계산 가정이 표시된다.
- [ ] 모바일 화면에서 주요 입력과 결과를 사용할 수 있다.
- [ ] 조건 변경 후 결과 갱신이 200ms 이내다.
- [ ] 사용자 입력값이 서버 로그에 기록되지 않는다.

## Verification

- [ ] 모바일/데스크톱 수동 확인
- [ ] 명도 대비 점검
- [ ] 조건 변경 성능 측정
