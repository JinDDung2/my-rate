## Summary

대회 제출 기준에 맞춰 데모 데이터, 테스트, 배포 URL, 문서 일치 여부를 최종 점검한다.

## Spec Reference

- 10. 비기능 요구사항
- 11. 완료 정의

## Scope

- 광고 1위와 내 조건 1위가 다른 데모 입력 준비
- 계산 엔진 테스트 T1~T7 전체 통과 확인
- 전 상품 우대조건 추출 결과 사람 검수 완료 확인
- 모든 조건 카드 원문 근거 확인
- 기획서/기능명세서 PDF와 실제 화면 기능 일치 확인
- 제출 기간 무중단 접근 가능성 점검

## Acceptance Criteria

- [ ] 배포 URL에서 조건 변경 시 랭킹이 실시간으로 바뀐다.
- [ ] 광고 1위와 내 조건 1위가 다른 데모 케이스가 존재한다.
- [ ] 계산 엔진 테스트 T1~T7이 전부 통과한다.
- [ ] 전 상품 `reviewed: true` 상태가 확인된다.
- [ ] 모든 조건 카드에 공시 원문 근거가 붙는다.
- [ ] 문서와 실제 기능 범위가 일치한다.

## Verification

- [ ] 배포 URL 스모크 테스트
- [ ] 테스트 전체 실행
- [ ] 제출 문서와 화면 대조
