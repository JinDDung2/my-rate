## Summary

사용자 입력 조건 기준 세후이자 내림차순 랭킹 테이블을 구현한다.

## Spec Reference

- F-05 실수령 기준 랭킹
- 4. 화면 구성 [B] 결과 랭킹 테이블
- 9. API 명세

## Scope

- 사용자가 선택한 기간 `saveTrm` 옵션이 있는 상품만 필터링
- 상품별 내 금리 및 세후이자 계산
- 세후이자 내림차순 정렬
- 동점 시 기본금리 높은 순 정렬
- 순위, 은행, 상품명, 광고금리, 내 금리, 세후실수령 표시

## Acceptance Criteria

- [ ] 기간 옵션이 없는 상품은 랭킹에서 제외된다.
- [ ] 세후이자 기준으로 내림차순 정렬된다.
- [ ] 세후이자가 같으면 기본금리가 높은 상품이 먼저 표시된다.
- [ ] 조건 변경 시 랭킹이 실시간으로 갱신된다.
- [ ] 금액은 천 단위 구분으로 표시된다.

## Verification

- [ ] 기간별 필터링 수동 확인
- [ ] 조건 변경 후 랭킹 변경 수동 확인
- [ ] 정렬 로직 테스트
