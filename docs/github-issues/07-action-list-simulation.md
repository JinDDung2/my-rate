## Summary

미충족 조건을 하나씩 추가했을 때 세후이자 증가분을 계산하고 상위 3개 액션을 제안한다.

## Spec Reference

- F-07 조건 충족 시뮬레이션
- 4. 화면 구성 [D] 액션 리스트

## Scope

- 현재 1위 또는 선택된 상품 기준 미충족 조건 산출
- 미충족 조건을 단독으로 추가 충족한 시나리오 계산
- F-03~F-04 재실행으로 세후이자 증가분 계산
- 증가액 내림차순 상위 3개 표시
- 조합 시뮬레이션은 제외

## Acceptance Criteria

- [ ] 미충족 조건 각각의 단일 추가 효과를 계산한다.
- [ ] 증가액이 큰 순서로 최대 3개만 표시한다.
- [ ] 증가액이 0원인 조건은 노출하지 않는다.
- [ ] 조건 조합은 계산하지 않는다.
- [ ] 금액은 천 단위 구분으로 표시된다.

## Verification

- [ ] 조건 추가 시뮬레이션 수동 확인
- [ ] 정렬 및 최대 3개 제한 테스트
