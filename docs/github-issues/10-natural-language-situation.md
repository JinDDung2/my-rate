## Summary

선택 기능으로 자연어 상황 입력을 8개 우대조건 코드로 매핑하는 API와 UI를 구현한다.

## Spec Reference

- F-10 자연어 상황 입력
- 8.3 런타임
- 9. API 명세 `POST /api/parse-situation`

## Scope

- 자유 텍스트 1~3문장 입력 UI
- 서버 라우트 `/api/parse-situation`
- LLM 호출 결과를 `ConditionCode[]`와 요약으로 반환
- 체크박스 자동 체크
- "AI가 이렇게 이해했어요" 요약 표시
- 5초 타임아웃
- 실패 시 수동 입력으로 조용히 폴백 및 에러 토스트 1회
- IP당 분 10회 레이트 리밋

## Acceptance Criteria

- [ ] 자연어 입력 결과가 표준 조건 코드로 매핑된다.
- [ ] 매핑된 조건의 체크박스가 자동 체크된다.
- [ ] 사용자 입력 텍스트는 서버 로그에 남기지 않는다.
- [ ] API 키는 서버 환경변수에서만 사용된다.
- [ ] 실패 또는 타임아웃 시 기존 수동 입력 플로우가 유지된다.
- [ ] 레이트 리밋 초과 시 적절한 에러를 반환한다.

## Verification

- [ ] 정상 매핑 수동 확인
- [ ] 타임아웃/실패 폴백 확인
- [ ] API 키 클라이언트 미노출 확인
