## Summary

월 납입액, 가입 기간, 적립 방식, 우대조건 8종을 입력하는 단일 페이지 입력 패널을 구현한다.

## Spec Reference

- F-02 조건 입력
- 3. 표준 우대조건 코드
- 4. 화면 구성 [A] 입력 패널

## Scope

- 월 납입액 입력: 10,000~1,000,000원, 만원 단위 스텝
- 가입 기간 선택: 6/12/24/36개월
- 적립 방식 선택: 정액적립/자유적립
- 우대조건 체크박스 8종 제공
- `OTHER`는 체크 불가 정보 표시용으로 처리
- 입력 변경 즉시 재계산 이벤트 연결
- 범위 밖 값 입력 시 인라인 경고 및 직전 유효값 유지

## Acceptance Criteria

- [ ] 제출 버튼 없이 입력 변경 즉시 결과가 갱신된다.
- [ ] 월 납입액 범위를 벗어나면 인라인 경고가 표시된다.
- [ ] 잘못된 월 납입액 입력 시 계산은 직전 유효값으로 유지된다.
- [ ] 기간은 6/12/24/36개월만 선택할 수 있다.
- [ ] `OTHER` 조건은 사용자가 체크할 수 없다.

## Verification

- [ ] 입력값 변경 수동 확인
- [ ] 유효성 에러 수동 확인
- [ ] 모바일 화면에서 입력 패널 확인
